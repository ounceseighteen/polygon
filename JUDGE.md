# Инструкция судьи

## 1. Запуск веб-интерфейса
    cd judge_app
    pip install -r requirements.txt
    python app.py --port 8080

Открыть http://localhost:8080

## 2. Что вы видите
- **Дашборд** — сетка 5×5 карточек команд: статус, порт, оценка.
- **Leaderboard** — таблица с разбивкой по метрикам и оценкой 2–5.
- **Team detail** — история замеров, хвост app.log, кнопки.
- **Events** — лента событий: запуски, падения, готовые замеры.
- **Settings** — порты, веса метрик, пороги оценки.

## 3. Порядок работы
1. Проверить, что у всех команд есть папка teams/teamXX/.
2. Нажать **Start all** — судья поднимет приложения на их портах.
3. Убедиться, что все зелёные. Красные — перезапустить или
   написать команде.
4. Перед финальным замером нажать **Re-seed all** — БД команд
   приводится к единому baseline.
5. Нажать **Run acceptance for all** — gate.
   Провалившие gate получают 2 и в зачёт метрик не идут.
6. Нажать **Run metrics for all** — замер скорости, покрытия,
   качества, логов, безопасности.
7. Открыть **Leaderboard** — оценки выставлены автоматически.

## 4. Как считается оценка
Сначала gate (acceptance-тесты от судьи). Не прошёл → 2.

Если прошёл, считается score:
    0.30*S_speed + 0.20*S_tests + 0.20*S_quality
  + 0.15*S_reliab + 0.10*S_sec + 0.05*S_docs

Перевод в оценку:
- score ≥ 0.85 → 5
- 0.70–0.84  → 4
- 0.50–0.69  → 3
- < 0.50     → 2

Предохранители (понижают оценку):
- Подмена tools/* → 2.
- Удаление функционала → 2.
- Нет ни одного теста → максимум 3.
- Остались except: pass → максимум 4.
- Coverage < 30% при высоком score → максимум 3.

## 5. Anti-cheat
- tools/* хешируются при старте, перед каждым замером хеш
  сверяется. Не совпал — метрика помечается tampered, оценка 2.
- Судья сам запускает приложение команды — команда не может
  «замерить себя сама».
- Перед финальным замером БД команд пересоздаётся из seed’а.
- На защите задайте 2–3 сюрпризных вопроса по diff’у.

## 6. Экспорт результата
- Кнопка **Export final report** — HTML/CSV со всеми метриками
  и оценками.
- Хранится в judge_app/reports/ с датой.

## 7. Частые проблемы
- **Команда упала** → смотреть Events и хвост app.log.
- **database is locked** → проверить, что в приложении включён WAL.
- **Замер нечестный** → убедиться, что bench запускается
  в один поток и с одинаковым профилем для всех.
- **score высокий, но оценка низкая** → смотреть плашку
  «почему не выше» на странице команды.
